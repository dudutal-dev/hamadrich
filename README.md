# המדריך – מלווה מסע אישי

PWA אישית (עברית, RTL, offline-first) שבונה סשן בחמישה שלבים – הגעה, שחרור, שיא, חזרה, אינטגרציה – ומתזמרת מעליו מוזיקה, קריינות, הנחיית נשימה וויזואל. בהשראת מבנה "Psychedelic Prayers" של טימותי לירי.

## מצבים
- **נשימה** 5–30 דק' · **מדיטציה** 20–60 · **מסע עמוק** 45–120 · **שינה** 15–45
- **אלבום כמסע** – ייבוא אלבום שלם (למשל 55 הרצועות של Psychedelic Prayers מ-Bandcamp); השלבים ממופים אוטומטית, אפשר לקצר בלי לחתוך רצועות.

## בזמן מסע
| מחווה | פעולה |
| --- | --- |
| נגיעה | עצירה / המשך |
| לחיצה ארוכה (~1 שנ') | עוד עשר דקות |
| החלקה למעלה | דלג לשלב החזרה |
| לחיצה ארוכה 3 שנ' | מסך חירום: דרון שקט, עיגון, חזרה הביתה, התקשר לאיש קשר |

## התקנה על הטלפון
1. `npm install && npm run build` → התיקייה `dist/` סטטית לחלוטין.
2. פריסה: GitHub Pages (יש workflow מוכן ב-`.github/workflows/pages.yml` – הפעל Pages עם מקור "GitHub Actions"), או כל אחסון סטטי.
3. בטלפון: פתח את הכתובת ב-Safari/Chrome → "הוסף למסך הבית".

## קול
הקריינות מובנית באפליקציה: 32 קטעים בעברית בקול "המדריך" (ElevenLabs, מודל eleven_v3), לפי מצב, כוונה ושלב, כולל קטע הרגעה למסך החירום. גם צלילי הנשימה הם הקלטות אמיתיות (ElevenLabs Sound Effects). הכול נמצא ב-`public/voice` וב-`public/breath`, נשמר במכשיר ועובד בלי רשת. אין צורך במפתח API.

התסריט נמצא ב-`docs/voice-script.md`, והנתונים (טקסט, הגייה ואורך) ב-`src/engine/voice-clips.json`.

## פיתוח
```
npm run dev       # localhost:5173
npm run build     # dist/
npm run preview   # בדיקת הבילד
```
Vite · React · TypeScript · Tailwind v4 · Dexie (IndexedDB) · Web Audio · vite-plugin-pwa.

## הערות iOS
- ה-AudioContext נפתח רק אחרי מגע – לכן מסך "הכנה".
- המשך נגינה עם מסך כבוי דרך MediaSession + לופ שקט.
- Wake Lock פעיל רק מחוץ לשלב השיא.

המדריך מלווה נשימה, מדיטציה ומסעות עצמאיים. הוא אינו כלי רפואי ואינו מחליף ליווי אנושי. כל הנתונים נשמרים במכשיר בלבד.
